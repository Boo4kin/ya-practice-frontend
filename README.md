# Frontend Practice

Учебный репозиторий по веб-разработке, созданный в рамках программы Яндекс Практикума.

В репозитории сохранены практические задания по базовой вёрстке и работе с HTML/CSS. Он отражает ранний этап обучения фронтенд-разработке и хранится как часть учебного портфолио.

## Стек

HTML · CSS · основы JavaScript

## Содержимое

- `index.html` — основная страница;
- `styles/` — стили проекта;
- `images/` — изображения;
- `texts.md` — исходные текстовые материалы.

Репозиторий не позиционируется как production-проект и сохранён прежде всего как учебная работа.
